## Reader changes

- Recognize optional `narrationSource: "SENTENCES"` in published texts. Use recorded sentence starts/ends for word-drill handoffs and sentence replays, preserving the earlier fallback for older publications.
- Keep each Armenian translation on one line, centered above its original English word. Account for glyph rounding, trailing letter spacing, punctuation and the available phone width. Expand the translation/word pair together when needed; exceptionally long labels can shrink below the configured preferred minimum to fit the row.
- Fix the reported wrapping of `անընդհատ`, `մարդաշատ` and `անձրևանոց`. The word and its translation stay together when the passage wraps.
- Pulse the translation on the first natural reading, each vocabulary repetition and sentence replays. Position updates within the same word do not repeatedly restart the pulse; paused playback and gaps between word clips do not trigger new pulses.
- Display reading-mode `displayName` values saved by admin. Stable IDs continue to select playback behavior; ordering/enabled state still come from settings.

## Fonts and caching

The existing immutable font identity and native cache implementation were verified rather than replaced. Added regression coverage for switching between identically labeled fonts, changed content versions and damaged native cache files. The existing Android test also verifies reuse after an app restart.

Admin upload validation checks actual font contents and alphabet support. The backend verifies stored bytes against their size and SHA-256. Mobile registers fonts under ID/hash-based family names and validates downloaded/cached bytes by size and font header before loading. Mobile does not independently recompute the SHA-256; these tests do not claim otherwise.

Saved font and mode changes take effect when the learner reopens a lesson. Settings requests bypass HTTP caching, while immutable font files can be reused. There is no live settings push into an already-open lesson.
