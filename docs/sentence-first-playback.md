# Sentence-only publications — 2026-11-14

The reader accepts both legacy manifest version 2 and sentence-only version 3. Version 3 includes a duration/sample-rate descriptor plus an asset for every sentence. Playback plans read each sentence file using local sample bounds while tracking progress and highlights in the lesson's virtual timeline. Word and phrase repetitions replay their original occurrence from the sentence, even for older version 3 publications containing standalone word clips. This preserves the original voice and emphasis while keeping the existing practice order. Legacy full-narration publications retain compatibility. The device may still compile a temporary practice track locally for accurate pauses; the server no longer generates a full lesson audio file.

Validated with TypeScript, Expo lint, and 116 tests, including sentence-file playback, seeking into later sentences, global progress mapping, contextual word repetitions, legacy standalone clips, and deep-learning sentence repetitions. Local mobile web playback of “14 law” exercised the contextual repetitions. Its 13 new library clips were verified sample-for-sample against the existing 24 sentence recordings; no new speech was generated. Native-device playback and a new store build remain untested/unreleased in this change. Release this reader before production starts publishing version 3 lessons; older installed builds reject that version.
